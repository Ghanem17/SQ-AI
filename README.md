# SQ AI

تطبيق تسويق ذكي من سما قاسيون: يخطط، ويوجّه صاحب المحل أثناء التصوير، ويصمم المحتوى وينشره ويروّج له، ويرد على الزبائن، ويقيس كلفة كل طلب.

## ما في التطبيق الآن

كل الشاشات مبنية وتعمل ببيانات تجريبية، بتصميم هادئ ودقيق: زوايا حادة، حدود رفيعة، وأرقام بخط ثابت العرض.

- **الترحيب والتسجيل:** شاشات تعريف بسحب يمين ويسار، تسجيل برقم الهاتف، ورمز تحقق من 6 خانات.
- **الرئيسية:** مهمة اليوم، كلفة الطلب، الطلبات، الرد، الريل بانتظار الموافقة، الرسائل، والخطة الشهرية.
- **التصوير:** قائمة لقطات، وكاميرا موجّهة بشبكة وإطار للمنتج وعدّ تنازلي وتسجيل بمدة كل لقطة.
- **«كيف بدك ريلك؟»:** ثلاث مستويات (أساسي، احترافي، متقدم) بأسعارها.
- **«ليش هالسعر؟»:** إيصال مفصّل بكل خطوة، والأداة أو المنصة التي تنفذها، وكلفتها.
- **النشر:** المنصات، كابشن يكتبه المساعد، ووقت النشر: أفضل وقت، الآن، أو يوم وساعة تحددها.
- **الترويج:** بدون، منخفض، متوسط، عالي، بعدد أيام ومنطقة، مع تقدير للوصول والطلبات وسقف الصرف.
- **مراجعة الطلب وتأكيده**، ثم مراجعة الريل النهائي والموافقة أو طلب تعديل.
- **الرسائل:** صندوق موحّد، ومحادثة يظهر فيها رد المساعد، والطلب الذي سجّله، وزر «تولَّ المحادثة».
- **الإعلانات:** الصرف مقابل السقف، الحملات، والترويج التلقائي للريل الأنجح.
- **التقرير:** كلفة الطلب عبر الزمن، الطلبات حسب المصدر، وأفضل الريلز.
- **المساعد:** «ما عندك فكرة؟» يقترح أفكارًا ويحوّلها لقائمة لقطات تفتح الكاميرا.
- **الخطة الشهرية:** الهدف، عدد الريلز مع الخصم، الجودة، المنصات، ميزانية الإعلانات، وجدول الشهر.
- **الوضع التلقائي:** تشغيل كامل بسقف صرف شهري، وقواعد، وخريطة «مين يشتغل على كل خطوة» لكل منصة.
- **لصانع المحتوى:** التعاونات، الأفكار، والنمو بدل الرسائل والإعلانات والتقرير.

الأسعار ومسار الأدوات في `packages/shared/src/pricing.ts` و`pipeline.ts`، ومغطاة باختبارات.

لا يوجد سيرفر بعد: تسجيل الدخول والردود تجريبية، **ورمز التحقق دائمًا `123456`**.

## التجربة على الموبايل

1. ثبّت تطبيق **Expo Go** من App Store أو Google Play.
2. على الكمبيوتر:

   ```bash
   npm install
   cd apps/mobile
   npx expo start
   ```

3. امسح رمز QR الذي يظهر بكاميرا الآيفون، أو من داخل Expo Go على أندرويد.

## خدمات بالقطعة

بدون اشتراك: الزبون يحكي مع المساعد شو بدو، ويرفق فيديو أو صورة إذا لزم. المساعد يستخرج تفاصيل الطلب فقط، والتطبيق يحسب الأدوات والكميات من التفاصيل (`planLines` في `packages/shared/src/services.ts`) ويسعّرها من أسعار fal الحية أو أسعار صاحب التطبيق، مع سعر الدولار وهامش الربح. الزبون يرى كل أداة وكلفتها قبل الموافقة، ثم يُنفَّذ الطلب خطوة بخطوة عبر fal:

- **مونتاج فيديوك:** قص، ترجمة مكتوبة، موسيقى.
- **إعلان من صورة:** Nano Banana Pro.
- **فيديو من نص:** Kling 3 مع موسيقى Lyria 2.
- **كتابة محتوى:** Claude.
- **تعليق صوتي:** ElevenLabs v4.

الأسعار والأرباح من الإعدادات، ثم «الأسعار والأرباح». الدفع يُفعَّل مع السيرفر.

## ربط الذكاء الاصطناعي (fal.ai)

كل نماذج الذكاء الاصطناعي تمر عبر مفتاح fal.ai واحد: Claude للمساعد والكابشن والردود (عبر موجّه fal المتوافق مع OpenAI)، وElevenLabs v4 للتعليق الصوتي، وNano Banana Pro للصور، وVeo 3.1 للقطات المولّدة، وLyria 2 للموسيقى، وTopaz لرفع الدقة. المونتاج على السيرفر بأداة ffmpeg.

المفتاح **لا يوضع داخل التطبيق** ولا يُرفع على GitHub. أنشئه من fal.ai بصلاحية **API** فقط، وضعه في ملف `apps/mobile/.env` على الكمبيوتر الذي يشغّل التطبيق:

```
FAL_KEY=...
```

بعدها شغّل `npx expo start`. واجهات `src/app/api/*+api.ts` تعمل على الكمبيوتر وتستخدم المفتاح، والموبايل يكلمها عبر نفس اتصال Expo. بدون مفتاح يعمل التطبيق بردود تجريبية ويوضح السبب (لا مفتاح، مفتاح خاطئ، أو رصيد منتهٍ).

ما يعمل بالمفتاح الآن: المساعد (أفكار وقوائم لقطات تفتح الكاميرا)، كتابة الكابشن، التعليق الصوتي، وشاشة «جرّب الرد على زبون».

متغيرات اختيارية: `AI_TEXT_MODEL` (الافتراضي `anthropic/claude-sonnet-5.5`) و`FAL_VOICE_MODEL` (الافتراضي `fal-ai/elevenlabs/tts/eleven-v4`). ويمكن استخدام `OPENROUTER_API_KEY` بدل `FAL_KEY` إذا لزم.

## هيكل المشروع

| المجلد | المحتوى |
|---|---|
| `apps/mobile` | تطبيق الموبايل: Expo SDK 58 وReact Native وTypeScript وExpo Router |
