# SQ AI

تطبيق تسويق ذكي من سما قاسيون: يخطط، ويوجّه صاحب المحل أثناء التصوير، ويصمم المحتوى وينشره ويروّج له، ويرد على الزبائن، ويقيس كلفة كل طلب.

## المرحلة الحالية: 1 (الأساس)

- شاشات التعريف الأربع بحركات وسحب يمين ويسار.
- إنشاء حساب وتسجيل الدخول برقم الهاتف، ورمز تحقق من 6 خانات.
- اختيار نوع الحساب: محل أو صانع محتوى.
- شاشة «اليوم» للمحل، والرئيسية لصانع المحتوى، ببيانات تجريبية.
- الوضع الفاتح والداكن، والعربية من اليمين لليسار.

لا يوجد سيرفر بعد. تسجيل الدخول تجريبي، **ورمز التحقق دائمًا `123456`**.

## التجربة على الموبايل

1. ثبّت تطبيق **Expo Go** من App Store أو Google Play.
2. على الكمبيوتر:

   ```bash
   npm install
   cd apps/mobile
   npx expo start
   ```

3. امسح رمز QR الذي يظهر بكاميرا الآيفون، أو من داخل Expo Go على أندرويد.

## هيكل المشروع

| المجلد | المحتوى |
|---|---|
| `apps/mobile` | تطبيق الموبايل: Expo SDK 58 وReact Native وTypeScript وExpo Router |
| `packages/shared` | ما يشترك فيه التطبيق والسيرفر: الألوان، والتحقق من الأرقام والرموز، وتنسيق الأرقام |

## الأوامر

```bash
npm test          # اختبارات الحزمة المشتركة (منها فحص تباين الألوان)
npm run typecheck # فحص الأنواع لكل الحزم
npm run lint      # فحص الكود
```
